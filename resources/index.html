Welcome to WebServer Ultimate - A High-Performance Web Server in C++! This is a simple web server built using C++ that supports handling multiple client connections concurrently. It is designed to be efficient and scalable, making use of non-blocking sockets and the epoll mechanism for event-driven I/O. The server can serve static files from a specified directory and supports basic HTTP methods such as GET. It also includes features like connection keep-alive and proper HTTP response handling. To get started, you can clone the repository, build the server using CMake, and run it to serve files
